# Purchase Order Tracking API

To run the API, you can open it in Visual Studio. I used Visual Studio 2022.

Run it by pressing F5. It should run the API with the following address: http://localhost:5025

To test just the API, open the **POTracking.Api.http** file and click on 'Send request' above the endpoint you would like to test.

The **POTracking.Api.http** file contains a few examples to get you started.
